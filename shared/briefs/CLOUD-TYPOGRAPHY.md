# Cloud Typography｜三方统一创作要求 v2（2026-11-21）

本要求由 Reina 最新反馈覆盖旧版 v1 中的“点击单词后自动重聚”。Luci、Gemini、DeepSeek 三方都以此为当前目标，使用独立工作区，可以分别选择自己的实现方案。

## 视觉与文本
- 保持天空主题，改为**降低亮度的灰蓝渐变**；云白色文字减少刺眼高光，不做霓虹灯效果。
- 文本使用**多行英文段落**，不再局限于 5 个大单词标题；推荐 150–250 个英文字母以上。
- 文字边缘柔和、有云雾层次，同时在最初应可读。
- 从秩序逐渐失序：字母缓慢漂移、旋转，独立运动但受到**连续、空间相关的风场**。混乱程度比 v1.0 明显更高，不是所有字母整体同步晃动。

## 交互（新版已确定）
- **每个字母是独立对象，不是整个单词。**
- 点击某个字母，它逐渐像云一样被风吹散：拉伸、云絮/粒子化、漩涡扰动、向主风向飘移、逐渐变稀和消失。
- **永久消散，不自动恢复**。仅用户主动点击“重新开始”时才复位整个作品。
- 点击空白天空 / 主动触发强风时，可令整段文字按风场分批吹散，形成更强的失序叙事。
- 风力与失序强度可调；优先兼顾电脑和手机屏幕。

## 允许的技术
HTML/CSS/JS、Canvas、p5.js、SVG/WebGL 都可以；重视性能、动效连贯、代码可读。
**若只靠透明度实现“消散”，须标为简化版，不可声称已有云雾粒子。**
