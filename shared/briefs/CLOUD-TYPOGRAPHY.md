# Cloud Typography｜三方统一创作说明 v1

## 背景
作品《云间来信》受思花《时间尽头的无序之书》的文字失序概念启发。原作者真实软件与源码不明，属于**原创改编**而不是直接复制素材。

## 视觉要求
- 保留现有柔和天空蓝渐变背景。
- 白色、可读且逐步有云朵质感的英文文字，画面整体轻盈克制。
- 字词在缓慢、连续的微风中轻轻移动、逐渐失序；相邻字符的运动应有相关性，避免每帧重新随机跳动。
- 电脑横屏优先，手机浏览器尽量可用。

## 确定的方案 A（不可擅自改变）
- 点击**一个完整单词**，它像云一样化成细小白色云絮或粒子，随风飘散。
- 片刻后重新凝聚成**原来的单词**。
- 其他词不应受影响，重复点击应稳定。
- 初版可分阶段实现模糊/淡出再恢复，最终目标仍是真正的云雾粒子，而非只改透明度。

## 技术与验收
- 三方可选择 HTML/CSS/JS、Canvas、SVG、p5.js 等不同实现，注重效果流畅和代码可理解。
- 验收：画面正常、五个独立点击、消散/重组、柔和微风、动画状态稳定、性能及移动端检查。
- 每个 AI 在自己的作品目录下维护源代码、个人配置及进度；共享规格仅经用户决定后更改。
