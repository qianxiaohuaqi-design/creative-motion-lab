# Creative Motion Lab｜长期学习路线

更新：2026-11-21。以下是规划，不代表功能已经实现。

## 学习约定
- 每个作品一个独立文件夹：源代码、视觉设计、参考索引、任务列表、复盘。
- 用户想亲自学习时：AI 先讲原理，再留小任务并审查代码。
- 用户明确要求 AI 做作品时：允许 AI 编写完整实现，但要保留注释与可供学习的说明。
- 多个 AI 可以分别试验不同方案，默认使用独立分支，避免直接覆盖线上版本。

## 第一阶段｜创意编程与动态艺术（进行中）
技术路径：VS Code、HTML/CSS/JavaScript → Canvas 2D / SVG → p5.js / 连续噪声与流场。

1. Cloud Typography / 云间来信：灵感来自文字有序到无序；原创蓝天、云字、微风、点击消散与重新凝聚。目前只有静态蓝天和独立单词基线。
2. 人停鱼行：鱼对象、粒子群、路径/流场、空间远近、信号灯（未开工）。
3. 夏天的手心：柳枝曲线、叶片分布、风力和图层（未开工）。
4. 春枝：路径生长、开花、形变、特效合成（未开工）。

阶段验收：至少三部可运行作品和源码，能够解释坐标、时间、插值、随机与连续运动的区别、事件、粒子生命周期。

## 第二阶段｜产品宣传与代码视频（规划）
SVG / GSAP / React / Remotion 等，制作 15–30 秒产品演示，理解动画时间线、镜头节奏、精确 UI 与视频输出。

## 第三阶段｜风格化视觉特效（规划）
p5.js、p5.brush、Manim、粒子/着色器、动态图表、手绘或水彩感动画。

## 第四阶段｜三维电影感（规划）
Three.js、Blender、材质、光照、摄像机、景深、运动与音频同步。

## 第五阶段｜生成式 AI 视频（规划）
文生视频、图生视频、分镜、角色一致性、视频编辑，与可控的代码动画合成。

## 第六阶段｜原创作品集（规划）
完整艺术短片、产品宣传、音乐视觉、游戏演出，保留过程文档和展示版本。

详细功能进度请读 shared/plans/PROJECT-STATUS.md；原视频参考索引请读 shared/references/VIDEO-INDEX.md。
