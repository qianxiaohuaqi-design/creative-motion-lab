# Gemini｜Cloud Typography（《云中来信》GitHub Pages 发布目录）

本目录已同步 **《云中来信 · A Letter from the Clouds》**（来源：`agents/gemini/projects/cloud-letter-gemini/`），作为 GitHub Pages `/gemini/` 入口的正式发布源码。

- **在线地址**：`https://qianxiaohuaqi-design.github.io/creative-motion-lab/gemini/`
- **自动部署**：推送至 `main` 分支后，由 `.github/workflows/deploy-pages.yml` 自动构建并发布至 GitHub Pages
- **资源路径**：`index.html` 内均采用相对路径（`./style.css`、`./script.js`），适配 GitHub Pages 子路径部署

## 核心特性

- 明亮通透晴空背景 + 远中近景软云 + 轻微 3D 视差镜头
- 英文书信按单个字母拆分为独立云絮对象，带柔和云雾边缘与独立漂浮/失序物理
- 单击/轻触字母后沿笔画轮廓化作云雾粒子永久消散（不自动恢复，仅 `RESET` 可复原）
- 长按召唤半抽象白鸽携小信封，沿拖拽方向扇翼滑翔，以流线风痕与云丝尾流吹散、雾化并带走文字
- 底部晴空玻璃控制区提供 `WIND`、`DISORDER`、`REACH` 与 `RESET`
