# Cloud Typography｜给其他 AI 的交接说明

请先阅读：仓库 AGENTS.md、shared/plans/PROJECT-STATUS.md、本目录 DESIGN.md、TASKS.md 和 README.md。

## 明确目标
原创的互动动态艺术《云间来信》：
- 保留当前天空蓝渐变背景和白色、居中、可读的英文文字。
- 让文字边缘逐步具备轻盈云雾质感；不要为写实牺牲可读性。
- 词语/字母随缓慢微风平滑漂浮，邻近元素运动相关，逐步轻微失序，不要每帧随机跳动。
- **交互方案 A 已确定**：点击完整单词 → 像云一样散成白色云絮/粒子，随风漂移和渐隐 → 暂停片刻 → 重新凝聚成原单词。
- 点击其它词应互不影响，重复点击不能导致状态损坏。
- 电脑横屏优先，移动屏幕也要基本可用。
- 必须保留可读代码、解释和可调参数，供初学者理解。

路径：agents/luci/projects/cloud-typography/

- 在线预览：https://reina-motion-lab.netlify.app

## 推荐的独立实现里程碑
M1：每个单词接收点击，使用 CSS 模糊/透明度完成消失与恢复（验证状态管理）。
M2：使用基于时间的连续运动（噪声/插值）实现柔和微风。
M3：字母级缓慢失序，同时仍按整个单词点击。
M4：Canvas 离屏字形采样 → 粒子散开与缓慢移动 → 反向重组。
M5：视觉打磨、性能、移动端、减少动画偏好、演示录制。

## 验收标准
- 初次加载正常、天空蓝白字不变、浏览器无异常报错。
- 五个单词都能独立触发；其他词不受影响。
- 被点击的词散开后可以自动重组，重复点击正常。
- 风场平滑缓慢，不抖动。
- 粒子有云雾质感，最终不只是简单隐藏 DOM。
- 任何新增资源都能在 Netlify 正确加载；相关配置位于仓库根目录 netlify.toml。
- 最终附功能清单、测试结果、实现原理、可调参数。
