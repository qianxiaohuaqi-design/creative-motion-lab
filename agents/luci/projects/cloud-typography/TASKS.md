# Cloud Typography / 云间来信 · 功能清单

更新：2026-11-21 · Luci v1.0 已实现；浏览器回归测试通过，线上部署以 Netlify 的 Ready 状态为准。

## 用户指定的七项功能
- [x] 天空蓝渐变背景
- [x] 白色文字排版
- [x] 文字拆为 5 个独立单词
- [x] 白云质感字体（CSS 多层软边、模糊云光）
- [x] 微风吹动文字、随时间逐渐失序
- [x] 点击单词后化作云雾粒子
- [x] 云雾重新凝聚成原单词

## 稳定性与交互
- [x] 独立单词触发，可同时让多个单词散开
- [x] 动画时长独立按时间计算，避免显示器帧率改变动画速度
- [x] 重复点击锁定，防止重入
- [x] WIND 0–5 调节与重新开始
- [x] 手机屏幕自适应，不出现水平溢出
- [x] 键盘 Enter/Space 与系统减少动画偏好
- [x] 不使用第三方代码依赖或外部素材
- [x] 桌面、移动端、键盘、重置、减少动画等浏览器自动化测试通过
- [ ] 实际用户在 Netlify 网页上进行美术主观验收（待查看最新网页后反馈）
