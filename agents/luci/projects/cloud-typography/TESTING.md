## 备注
- “白云字体”使用多层 CSS 软边和发光模拟，属于风格化云质感，而非真实物理体积云模拟。
- 粒子使用字形不透明像素采样，并叠加大小不同、透明度不同的柔软光团。
- 同一时间触发多个单词时，各自状态独立；过多粒子会增加浏览器工作量，当前设有限量。
- 线上用户的实际美术主观评价仍需要打开最新 Netlify 页面再检查。
