# Cloud Typography v1.1｜本地测试记录

环境：2026-11-21，Chromium + Playwright。为规避测试环境的本地 URL 导航限制，在测试页注入等价的 HTML / CSS / JavaScript 原文件后执行交互。

## 验证结果
- 1440×900 桌面：生成 204 个 .letter 元素，JS pageerror 为 0，页面无水平溢出。
- 390×844 手机：生成 204 个 .letter 元素，JS pageerror 为 0，页面无水平溢出。
- 两种尺寸：点击首字母并运行约 2.7 秒后，该字母保持 gone，其他字母没有随之消失。
- “重新开始”：清除 gone 状态，恢复初始字符。
- “吹散整段”：约 3.5 秒后，桌面 138 个字母、手机 140 个字母已经消散；剩余的还在按时间差消散。
- 使用 node --check 检查 script.js，语法正确。

## 限制
- 本地测试与视觉截图不等于所有设备、网络或线上真实环境验收。
- 云雾采用 Canvas 2D 多层柔边粒子，而不是物理体积云模拟。
- 不保证长文本中每个字母在极高混乱度下始终可读；失序本身就是艺术效果。
