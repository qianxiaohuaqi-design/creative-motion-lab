# 00 · Cloud Typography — 云间来信（工作名）

> 状态：概念讨论中 / Stage 00 基础实验。这里先搭建可运行的网页骨架，核心动画由学习者一步步实现。

## 灵感来源与原创改编
参考思花《时间尽头的无序之书》关于“文字逐渐出现、随机偏移与旋转随字符数量增大”的公开作品描述。**原作具体使用的软件与工程尚未确认。**

我们的改编方向是：天空蓝渐变背景、云絮质感文字、缓慢微风造成秩序松动；用户点击单词后，该词分解为云雾粒子，并随风逐渐消散。作品不使用原视频的素材。

## 技术选择（学习路线）
- 第一阶段：**HTML + CSS + 原生 JavaScript**。在 Chrome 打开网页，先练习文字布局、事件、时间与 DOM。
- 第二阶段：**Canvas 2D**。用离屏画布将文字转换成像素采样点，制作真正的散开粒子。
- 第三阶段：**连续噪声 / 风场**，让相邻字符运动相关，而不是每帧重新抽取随机数。
- 最后：可以使用浏览器录制 / FFmpeg 输出视频，或保留为可交互网页艺术。

无须 Blender 或 After Effects。VS Code + 浏览器就足够入门。

## 运行方式
1. 使用 VS Code 打开仓库根目录。
2. 打开此目录的 `index.html`。
3. 可以直接用 Chrome 打开，也可以使用 VS Code 的 Live Server 扩展（推荐，保存自动刷新）。
4. 目前只能看到**静态的天空背景与文字**。点击消散、风场、粒子等留作练习，尚未实现。

## 学习顺序
- [ ] L00：运行页面，辨认 HTML / CSS / JS 各自职责。
- [ ] L01：拆分句子为单词，理解 DOM 元素及坐标。
- [ ] L02：点击单词，先做透明度下降 / 模糊的简易消散。
- [ ] L03：微风：用时间和噪声使词语缓慢漂浮。
- [ ] L04：失序：字符级偏移随时间或已出现字符数增长。
- [ ] L05：Canvas 粒子消散：离屏文字采样，生成云雾粒子。
- [ ] L06：视觉调校、交互细节、性能检查、录屏导出与复盘。
