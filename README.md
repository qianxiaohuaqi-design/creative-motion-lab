- 尚无：微风、点击消散、云雾粒子、自动重组。

## 给其他 AI
先读 AGENTS.md 和 Cloud Typography 的 AI-HANDOFF.md，再决定如何实现。建议新开分支，不要未经验收覆盖 main；main 推送会自动更新 Netlify。

## 学习方式
用户想亲手学：讲原理、布置练习、复盘。用户明确要求 AI 直接做：允许实现，但须记录设计与技术细节，供之后学习。
